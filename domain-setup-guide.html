Your new website is ready! This guide will walk you through connecting your domain name starship-solutions.com (which you own at GoDaddy) to your new website — with added security protection through Cloudflare.

🛡️ Why We're Using Cloudflare (Free Security Protection)

We're routing your website through Cloudflare to protect your business. Here's what you get for free:

  • DDoS Protection — Blocks attacks that try to crash your website
  • Firewall — Stops hackers from exploiting common vulnerabilities
  • Bot Protection — Prevents malicious bots from scraping your content
  • SSL Certificate — Free security certificate (the padlock icon in browsers)
  • Faster Loading — Your site loads faster because Cloudflare caches it on servers worldwide
  • Hides Your Server — Attackers can't directly target your website hosting
  • Analytics — See how many people visit your site and where they're from

Think of Cloudflare as a security guard that stands between the internet and your website, checking everyone who wants to visit.

Part A: Set Up Cloudflare FREE
1

Create a Cloudflare Account

  1. Open your web browser and go to www.cloudflare.com
  2. Click Sign Up in the top right corner
  3. Enter your email address and create a password
  4. Click Create Account
  5. Check your email and click the verification link
💡 Already have a Cloudflare account?
Just log in and skip to Step 2.
2

Add Your Domain to Cloudflare

  1. Once logged in, click Add a Site or Add Site
  2. Type in: starship-solutions.com
  3. Click Add Site
  4. When asked to choose a plan, select Free (scroll down if needed)
  5. Click Continue
3

Review DNS Records

Cloudflare will scan your existing DNS records. Now we need to set them up correctly for your new website.

Delete any existing A or CNAME records that Cloudflare found (if any), then add these new records:

Add these 4 A records:

Type Name Content Proxy Status
A @ 185.199.108.153 Proxied (orange cloud ON)
A @ 185.199.109.153 Proxied (orange cloud ON)
A @ 185.199.110.153 Proxied (orange cloud ON)
A @ 185.199.111.153 Proxied (orange cloud ON)

Add this CNAME record:

Type Name Content Proxy Status
CNAME www axpinto-145352.github.io Proxied (orange cloud ON)
⚠️ Important: The Orange Cloud

Make sure the Proxy Status shows an orange cloud (not gray). This is what enables Cloudflare's security protection. Click the cloud icon to toggle it on if it's gray.

For each record:

  1. Click Add Record
  2. Select the Type (A or CNAME)
  3. Enter the Name (@ or www)
  4. Enter the Content (the IP address or domain)
  5. Make sure the orange cloud is ON (Proxied)
  6. Click Save

When done, click Continue

4

Write Down Your Cloudflare Nameservers

Cloudflare will show you two nameservers. Write these down or take a screenshot — you'll need them in the next part.

They will look something like:

  • adam.ns.cloudflare.com
  • bella.ns.cloudflare.com

(Your actual names will be different — Cloudflare assigns random names)

📝 Write Your Nameservers Here:

2. _________________________________.ns.cloudflare.com

Keep this Cloudflare tab open — you'll come back to it later.

Part B: Update GoDaddy Nameservers
5

Log Into GoDaddy

  1. Open a new browser tab and go to www.godaddy.com
  2. Click Sign In in the top right corner
  3. Enter your GoDaddy username and password
6

Find Your Domain

  1. Go to My Products or Domains
  2. Find starship-solutions.com in your list
  3. Click on the domain name to open its settings
7

Change Nameservers to Cloudflare

  1. Look for a section called Nameservers
  2. Click Change or Manage next to nameservers
  3. Select Enter my own nameservers (advanced) or Custom
  4. Delete any existing nameservers
  5. Enter the two Cloudflare nameservers you wrote down in Step 4
  6. Click Save or Continue
  7. Confirm the change if prompted (GoDaddy may show a warning — this is normal)
⚠️ GoDaddy Warning Message

GoDaddy may warn you that changing nameservers will affect email or other services. If you only use this domain for your website (no email), it's safe to proceed. If you have email on this domain, contact your web developer first.

✓ Done with GoDaddy!

You can close GoDaddy now. You won't need to make changes there again — everything else will be managed through Cloudflare from now on.

8

Tell Cloudflare to Check

  1. Go back to your Cloudflare browser tab
  2. Click Done, check nameservers
  3. Cloudflare will check if GoDaddy's nameservers have been updated
⏳ Waiting Period

Nameserver changes can take a few minutes to 24 hours to take effect. Cloudflare will send you an email when your site is active. You can also check back later — Cloudflare will show a green checkmark when it's working.

Part C: Configure Cloudflare Security Settings

Once Cloudflare shows your domain is active (green checkmark), configure these security settings:

9

Enable HTTPS (SSL/TLS)

  1. In Cloudflare, click on SSL/TLS in the left sidebar
  2. Click on Overview
  3. Set the encryption mode to Full
What this does:

Encrypts all traffic between visitors and your website, showing the secure padlock icon in browsers.

10

Force HTTPS (Always Use Secure Connection)

  1. Still in SSL/TLS section, click on Edge Certificates
  2. Find Always Use HTTPS and turn it ON
What this does:

If someone types "http://" (insecure), they'll automatically be redirected to "https://" (secure).

11

Enable Bot Protection

  1. Click on Security in the left sidebar
  2. Click on Bots
  3. Make sure Bot Fight Mode is turned ON
What this does:

Automatically challenges or blocks malicious bots trying to attack or scrape your website.

12

Set Security Level

  1. Still in Security section, click on Settings
  2. Find Security Level
  3. Set it to Medium (good balance of security and user experience)
13

Enable Browser Integrity Check

  1. In Security > Settings
  2. Find Browser Integrity Check
  3. Make sure it's turned ON
What this does:

Checks that visitors are using real web browsers (not automated attack tools).

Part D: Final GitHub Setup
14

Configure GitHub Pages

Finally, tell GitHub about your custom domain:

  1. Go to your GitHub repository (your web developer can provide the link)
  2. Click on Settings (tab near the top)
  3. In the left sidebar, click Pages
  4. Under "Custom domain", enter: starship-solutions.com
  5. Click Save
  6. Do NOT check "Enforce HTTPS" — Cloudflare handles this for you
⚠️ Leave "Enforce HTTPS" Unchecked

Since Cloudflare is handling your SSL certificate, you don't need GitHub's HTTPS enforcement. Checking it may cause conflicts.

Troubleshooting

Cloudflare says "Pending Nameserver Update":

  • Nameserver changes can take up to 24 hours
  • Double-check that you entered the nameservers correctly in GoDaddy
  • Click "Re-check now" in Cloudflare to check again

Website shows "525" or "526" error:

  • Go to Cloudflare > SSL/TLS > Overview
  • Make sure it's set to "Full" (not "Full (strict)")

Website shows old content:

  • Clear your browser cache: Press Ctrl + Shift + R (Windows) or Cmd + Shift + R (Mac)
  • In Cloudflare, go to Caching > Configuration and click "Purge Everything"

"Too many redirects" error:

  • In Cloudflare, go to SSL/TLS > Overview
  • Make sure it's set to "Full" (not "Flexible")
  • Make sure "Enforce HTTPS" is OFF in GitHub Pages settings

Website is slow or not loading:

  • Check Cloudflare status at cloudflarestatus.com
  • Make sure the orange cloud (Proxy) is ON for your DNS records
