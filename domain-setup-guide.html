Domain Setup Guide for starship-solutions.com

What This Guide Will Help You Do

Your new website is ready! This guide will walk you through connecting your domain name starship-solutions.com (which you own at GoDaddy) to your new website. Once complete, anyone who types in starship-solutions.com will see your beautiful new site.

⏱ Estimated time: 15-20 minutes

1

Log Into Your GoDaddy Account

  1. Open your web browser and go to www.godaddy.com
  2. Click Sign In in the top right corner
  3. Enter your GoDaddy username and password
  4. Once logged in, you'll see your GoDaddy dashboard
2

Find Your Domain Settings

  1. Look for a menu item called My Products or Domains
  2. Find starship-solutions.com in your list of domains
  3. Click on the domain name or click the DNS button next to it
  4. You should now see a page titled "DNS Management" or "DNS Records"
✓ You're in the right place if:
You see a table with columns like "Type", "Name", "Value", and "TTL"
3

Remove Old A Records

  1. Look through the list for any rows where the Type column says A
  2. If the Name column shows @ — these need to be deleted
  3. Click the pencil icon (edit) or trash icon (delete) next to each old A record
  4. Confirm the deletion when asked
⚠️ Don't worry!
It's normal to delete old records. We're replacing them with new ones that point to your new website.
4

Add New A Records (4 Total)

Now add these 4 new records. You'll need to click Add or Add Record for each one:

Type Name Value (Points to) TTL
A @ 185.199.108.153 600 (or "10 minutes")
A @ 185.199.109.153 600 (or "10 minutes")
A @ 185.199.110.153 600 (or "10 minutes")
A @ 185.199.111.153 600 (or "10 minutes")

For each record:

  1. Click Add or Add Record
  2. Select A as the Type
  3. Enter @ in the Name field
  4. Enter the number (like 185.199.108.153) in the Value field
  5. Set TTL to 600 or select "10 minutes" from dropdown
  6. Click Save
  7. Repeat for all 4 records
5

Add CNAME Record for "www"

This makes sure www.starship-solutions.com also works:

Type Name Value (Points to) TTL
CNAME www axpinto-145352.github.io 600 (or "10 minutes")
  1. Click Add or Add Record
  2. Select CNAME as the Type
  3. Enter www in the Name field
  4. Enter axpinto-145352.github.io in the Value field
  5. Set TTL to 600
  6. Click Save
✓ Done with GoDaddy!
You can now close GoDaddy. The changes will take some time to spread across the internet (usually 15 minutes to a few hours, sometimes up to 24 hours).
6

Wait for Changes to Take Effect

DNS changes (what you just did) take time to spread across the internet. This is called "propagation."

  • Minimum wait: 15 minutes
  • Typical wait: 1-4 hours
  • Maximum wait: 24-48 hours (rare)
💡 How to Check If It's Working

Visit www.dnschecker.org and type in starship-solutions.com

When you see green checkmarks with numbers starting with 185.199, it's working!

7

Turn On Security (HTTPS)

Once the DNS changes have taken effect (Step 6), do this:

  1. Go to your GitHub repository (your web developer can provide the link)
  2. Click on Settings (tab near the top)
  3. In the left sidebar, click Pages
  4. Under "Custom domain", make sure it shows starship-solutions.com
  5. Check the box that says Enforce HTTPS
  6. Wait 5-10 minutes for the security certificate to activate
⚠️ If "Enforce HTTPS" is grayed out

This means DNS hasn't fully propagated yet. Wait a bit longer and try again.

If all the links work and show your new website, you're all done! Your new Starship Solutions website is now live at your custom domain.

Troubleshooting

If you see your OLD website:

  • Clear your browser cache: Press Ctrl + Shift + R (Windows) or Cmd + Shift + R (Mac)
  • Try opening the site in a private/incognito browser window
  • Wait longer — DNS changes may still be propagating

If you see a "404 Not Found" error:

  • DNS may not have fully propagated — wait a few more hours
  • Double-check that all 4 A records were added correctly

If HTTPS isn't working:

  • Make sure "Enforce HTTPS" is checked in GitHub Pages settings
  • Wait up to 24 hours for the security certificate to be issued

Need Help?

Contact your web developer if you run into any issues.
